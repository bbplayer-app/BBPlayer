# BBPlayer OTA Design

<!-- impeccable:direction-seed 3f4c3690; choice canon; user-pinned -->

## Form

A restrained operational dashboard using the familiar Expo OTA information hierarchy and shadcn's Nova component grammar. The user's pinned Expo reference and semantic-theme requirement override the seed's assigned experimental direction.

## Type

Geist carries interface labels, headings, and data. Headings are compact and direct; identifiers use monospace only where their fixed-width structure helps scanning.

## Material

Flat shadcn surfaces, quiet borders, and semantic muted layers. Cards group summaries and charts; tables remain the primary representation for operational entities. No decorative material, custom palette, or branded theme is added.

## Ground

Use only shadcn semantic tokens for backgrounds, foregrounds, borders, state, charts, selection, and scrollbars. The existing BBPlayer application icon and the “BBPlayer OTA” name provide the brand signal.

## Motion and Adaptation

Motion is limited to component state transitions. On narrow screens the sidebar becomes an off-canvas sheet, metric grids stack, low-priority table columns disappear, and essential fields remain visible with deliberate truncation. Navigation remains full document navigation across the seven Vite page entries.
