---
title: 共享歌单与协同编辑
---

共享歌单可供其他用户订阅，也可以通过邀请链接授权协作者编辑。

:::note
开启共享、订阅和共享同步使用独立的 **BBPlayer 账号**。请在 **我的 → BBPlayer 账号** 中注册或登录，无需使用 Bilibili Cookie 验证共享身份。
:::

## 开启共享

1. 打开可编辑的普通本地歌单，在更多菜单中选择 **设为共享歌单**。
2. 未登录时，先按提示登录 BBPlayer 账号，再返回完成操作。
3. 开启后，通过 **共享设置** 复制链接：
   - **订阅链接（只读）**：对方可以订阅和播放，不能修改云端内容。
   - **协作编辑邀请链接**：包含邀请码，对方加入后可添加、删除和排序歌曲。
4. 创建者可以重置协作编辑邀请链接，使旧邀请码不再用于新的加入请求。

:::caution
当前没有将共享歌单直接恢复为非共享歌单的操作。创建者删除共享歌单会使其他成员失去访问权限；删除前请确认影响范围。
:::

## 订阅共享歌单

可打开他人分享的网页链接，通过页面入口进入 BBPlayer；也可以在 **音乐库 → 播放列表 → + → 订阅共享歌单** 中手动输入。

1. 粘贴分享链接或歌单 ID。
2. 如需编辑权限，使用包含邀请码的链接，或填写编辑者邀请码。
3. 点击「订阅」进入预览页，核对创建者、曲目数量及预览曲目。
4. 登录 BBPlayer 账号后确认订阅，将歌单加入音乐库。

## 角色与权限

| 角色                 | 云端权限                                                         |
| -------------------- | ---------------------------------------------------------------- |
| 创建者（Owner）      | 修改歌单信息，添加、删除和排序曲目，管理邀请码，以及删除共享歌单 |
| 编辑者（Editor）     | 添加、删除和排序曲目；不能修改云端歌单基本信息                   |
| 订阅者（Subscriber） | 获取和播放歌单内容，不能修改云端内容                             |

编辑者或订阅者删除本地的共享歌单时，会退出该歌单，不会删除创建者的云端歌单。

## 同步与离线使用

编辑产生的更改会尝试同步到云端，其他成员通过同步获取更新。同步受网络和登录状态影响；失败时请查看应用提示及同步失败记录，不应视为即时同步。

已下载的曲目可离线播放。共享歌单同步不会替代音频下载，也不会备份其他本地歌单和全部应用数据。
