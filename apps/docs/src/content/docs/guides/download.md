---
title: 下载与导出
---

## 下载音频

- **下载单曲**：在本地歌单中打开歌曲右侧的菜单，选择「缓存音频」；也可以使用播放器更多菜单中的下载入口。
- **下载整个歌单**：在本地歌单详情页点击下载按钮并确认。已完成下载的曲目不会重复下载。
- **查看下载**：打开 **我的 → 下载** 查看已下载的曲目；歌单中的下载按钮还可进入下载任务页面。

下载完成后，可以在无网络时播放对应音频。仅将歌曲加入歌单不会下载音频；最近播放过的内容也可能只有部分缓存，离线收听前建议主动下载。

## 导出音频（仅 Android）

BBPlayer 可将已下载的音频导出为 `.m4a` 文件，并按配置写入封面、歌曲信息和已缓存的歌词。

1. 打开 **我的 → 下载**。
2. 使用单曲菜单中的「导出」，或选择多首歌曲后使用批量导出。
3. 在系统目录选择器中选择保存位置。系统不支持目录选择时，应用会使用 `Music/BBPlayer` 目录；旧版 Android 可能需要存储权限。
4. 在导出设置中配置文件名模板、内嵌歌词、逐字歌词转换和封面裁剪等选项。
5. 开始导出，并查看完成或失败提示。

:::note
内嵌歌词使用已保存到本地的歌词，不会在导出时自动补全。需要内嵌歌词时，请先在播放器歌词页加载并确认歌词。
:::

如果部分歌曲缺少封面，可在 **设置 → 下载与存储 → 下载缺失封面** 中补充下载，再重新导出。

## 存储与流量

音频大小取决于内容时长和音源码率，下载会消耗网络流量和设备空间。可在「设置 → 下载与存储」查看占用、调整同时下载数量或清理缓存。

缓存保存在应用管理的私有目录中。如需在其他播放器使用音频，请使用导出功能。数据备份与音频导出用途不同，备份文件不包含已下载的音频文件。
