title: 安装
---

## Android

前往 [GitHub Releases](https://github.com/bbplayer-app/BBPlayer/releases)，在目标版本的 **Assets** 中下载适合设备架构的 APK 文件并安装。大多数近期 Android 手机使用 `arm64-v8a`；其他设备请根据其处理器架构选择。

首次安装时，系统可能要求允许浏览器或文件管理器「安装未知应用」。按系统提示授权后继续安装。

## 更新

在 **设置 → 通用 → 检查更新** 中检查新版本，也可以从 GitHub Releases 下载 APK 更新。覆盖安装通常会保留应用数据；卸载前请先通过「设置 → 数据与备份」备份本地数据。

## iOS

仓库已包含 iOS 实现，但当前自动发布流程仍以 Android APK 为主。iOS 的安装渠道及可用版本请以项目发布说明为准，不要将 Android APK 用于 iPhone。

:::note
桌面歌词、状态栏歌词、车载歌词和音频导出等功能目前仅在 Android 上提供，具体支持范围见对应指南。
:::
