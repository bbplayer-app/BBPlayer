BBPlayer 是基于 React Native 与 Expo 构建的开源 Bilibili 音频播放器，支持在线播放、本地歌单、音频缓存和歌词显示。

## 开始使用

1. 按照[安装指南](/guides/install/)安装应用。
2. 在「搜索」页面输入关键词、视频编号或 Bilibili 链接，查找并播放内容。
3. 将常听的曲目添加到[本地歌单](/guides/playlist/)，需要离线收听时提前[下载音频](/guides/download/)。
4. 根据收听内容选择[音乐或播客模式](/guides/podcast/)，并在[设置](/guides/settings/)中调整播放行为和歌词显示。

## 账号与数据

「我的」页面分别提供 **Bilibili 账号**和 **BBPlayer 账号**入口，两者用途不同：

- **Bilibili 账号**：用于访问个人收藏夹、订阅合集、稍后再看，以及需要登录的 Bilibili 功能。
- **BBPlayer 账号**：用于共享歌单及协同编辑，不需要绑定 Bilibili 账号。

普通本地歌单保存在设备上。迁移设备或重新安装前，可在「设置 → 数据与备份」导出备份；共享歌单不会自动备份全部本地数据。
